# 🔐 Self-Reflective Agentic AI Framework for Automated Code Auditing

This project implements a **Self-Reflective Agentic AI System** that automatically audits source code for **quality**, **security vulnerabilities**, and **logical bias**.  
Unlike traditional single-pass tools, the system applies a **self-reflection loop** to re-evaluate its own findings, reducing false positives and improving reliability.

🎓 Designed as an **MCA Final Semester Project**  
🎯 Research-oriented and aligned with **Google / Big Tech Software Engineering practices**

---

## 🚀 Key Features

- Multi-agent architecture for independent code analysis
- AST-based code quality evaluation
- Rule-based security vulnerability detection
- Logical bias and fairness analysis
- Self-reflective reasoning loop for error correction
- Weighted scoring mechanism with confidence adjustment
- Explainable and structured audit reports

## 🧪 How It Works

1. User submits source code
2. Independent agents analyze:
   - Code quality
   - Security vulnerabilities
   - Logical bias
3. Initial results are aggregated
4. Self-reflection engine re-evaluates findings
5. Scoring engine computes final confidence score
6. Structured audit report is generated
